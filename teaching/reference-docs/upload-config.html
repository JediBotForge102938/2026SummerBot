Configuration reference

Use the shared robot configuration.

The team robot configuration files live in the robot-configs\ folder. Treat this folder as the source of record for the configurations used by the robot and simulator.

When you run the TeamCode launch configuration in Android Studio, the configuration is uploaded automatically. There is no separate upload command to run.

After deployment, open the Driver Station robot configuration screen and select the profile prepared for the current exercise or robot.
