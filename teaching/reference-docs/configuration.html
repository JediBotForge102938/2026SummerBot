Use the names exactly.

The drive-only profile maps four motors to these names:

Hub portPhysical positionCode name
0Left rearleft_back_drive
1Right rearright_back_drive
2Right frontright_front_drive
3Left frontleft_front_drive

The same names work in the simulator's StarterBot mapping. The repository copy in robot-configs\ is the source of record for the physical robot and simulator; see S2-03 for the map and S2-04 for the repair exercise.

BioBuzz internal IMU

The BioBuzz Control Hub's built-in REV Controller IMU is a separate I2C device, not a motor on Hub port 0. Configure it at I2C Bus 0, Port 0, name it imu, and keep the XML entry complete: <ControlHubImuBHI260AP name="imu" port="0" bus="0" />. The lesson OpModes use hardwareMap.get(IMU.class, "imu"), so both the configuration type and name must match.
