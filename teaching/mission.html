North star

Build confidence before complexity.

Enable a mostly novice FTC team to learn robot software by experimenting safely without requiring continuous access to the physical robot, and build enough confidence to contribute working opmodes to the team.

The simulator is a real practice path, not a backup. Students run working examples first, make predictions, compare results, and explain what changed. Tank drive comes before mecanum; Java vocabulary is introduced only when it helps explain the code in front of them.
