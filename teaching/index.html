Session 1: workflow, hardware, and drive control

S1-01 · From INIT to LOOP

Launch the simulator, select the preconfigured robot and OpMode, drive, then connect the experience to init() and loop().

S1-01B · Drive the real robot

Use the Android Studio app run configuration and Driver Station to deploy and safely drive the preconfigured robot.

S1-02 · Fixing tank drive

Diagnose incorrect motor directions, make one focused fix, and retest the four-wheel arcade drive.

S1-03 · Optional tank drive

Convert arcade control to tank control so the left and right sticks drive the matching sides.

Session 2: mecanum and control

S2-01 · Mecanum basics

Test forward, strafe, and turn one motion at a time before combining them.

S2-01B · Drive the mecanum robot

Compare the simulator tests with the physical mecanum drivetrain.

S2-02 · Bumper speed toggle

Add a small stateful control feature without changing the drive model.

S2-02B · Test the speed toggle

Verify the repaired button behavior on the physical robot.

S2-03 · Working with Hardware Map

Use robot-configs\ as the source of record for the robot and simulator.

Session 3: configuration troubleshooting

S3-04 · Repair a robot configuration

Use simulator behavior and the StarterBot profile to repair a deliberately miswired exercise copy.
