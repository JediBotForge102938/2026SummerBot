Mecanum movement

Use the lesson OpMode to discover how four angled wheels combine to move forward, sideways, and around a turn.

Drive in the simulator

  1. Launch the simulator with the Android Studio Simulator run configuration.
  2. Select the preconfigured robot configuration, then select [S2-01] Mecanum.
  3. Press INIT and START. Release the controls between each test.

Test one motion at a time

ControlMotionExpected observation
Left stick YForward/backAll four wheels cooperate to move along the robot's length.
Left stick XStrafeThe robot moves sideways without pointing in a new direction.
Right stick XRotateThe robot rotates around its center.
Two inputs togetherCombined motionThe robot follows a diagonal or curved path.

Before each single-stick test, tell your team what you predict. Afterward, explain what you observed and what you would test next. Watch the telemetry values change as you move the stick.

How mecanum wheels work

Each wheel has rollers mounted at an angle. The rollers are not all aligned the same way: viewed from above, this robot uses an X layout. The front-left and rear-right rollers use one diagonal, while the front-right and rear-left rollers use the opposite diagonal.

Wheel direction and effective motion

How to read it: LF = left front, RF = right front, LB = left back, and RB = right back. The simple arrows beside each wheel show that wheel's direction for the selected input. They are separate from the effective motion written below each panel. The roller layout remains an X when viewed from above: LF/RB use \, while RF/LB use /.

Navigate the code

  1. Stop the OpMode.
  2. Use Android Studio's Project view to open TeamCode/src/main/java/org/firstinspires/ftc/teamcode/teaching/session2/S2_01_MecanumTeleOp.java. Search Everywhere with Shift+Shift is also available.
  3. Find init() and identify the four motor names and the reversed left-side motors.
  4. Find loop(). Identify the three inputs: forward, strafe, and rotate.
  5. Look at the four setPower expressions. Each wheel receives a different combination of those three inputs.

What you should be able to explain

By the end of this lesson, every student should be able to describe mecanum movement as a combination of forward, strafe, and rotation, predict the result of each single-stick input, and explain why the four wheel-power formulas are different.

If a motion is confusing, return to one stick at a time. Do not diagnose a combined-motion problem before checking the basic motions.
