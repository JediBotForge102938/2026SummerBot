S3-04 · Repair a robot configuration

Use the simulator's behavior to find and fix a hardware-map mistake.

Course map Mission Resources Instructor notes
Configuration troubleshooting

The exercise configuration is a copy of the StarterBot profile with its motor ports jumbled. Use the working StarterBot configuration as the solution reference, then iterate with the simulator until the exercise drives normally.

Start with the solution reference

  1. Launch the simulator and select Stryker: StarterBot.
  2. Run a forward, strafe, and turn test with a teaching OpMode.
  3. Compare robot-configs\starterbot-drive-only.xml with the port table in S2-03.
  4. Explain why each configuration name must remain paired with its correct port.

Run and repair the exercise

  1. Open robot-configs\lessons\s3_04_configuration_exercise.xml. This is the exercise copy; do not change the shared starter profile.
  2. Launch the simulator and select Stryker: S3-04 Configuration Exercise.
  3. Run forward, strafe, and turn tests. Describe exactly what is funny or unexpected before editing anything.
  4. Compare the exercise XML with starterbot-drive-only.xml. Find the jumbled port assignments.
  5. Fix the exercise XML, rebuild or reload the simulator as needed, and repeat the same three tests.
  6. Iterate until the exercise behaves like the working StarterBot, then explain how the simulator helped identify the wiring-map error.

What you should be able to explain

By the end of this lesson, every student should be able to use a known-good configuration as a reference, connect an unexpected drive pattern to a port assignment, and prove a repair with repeatable simulator tests.

Change one value at a time and rerun the same tests. A clear prediction before each test makes the debugging evidence useful.
