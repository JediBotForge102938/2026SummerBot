S2-02B · Test the speed toggle on the robot

Deploy and test the repaired button-state behavior on the physical robot.

Course mapMissionResourcesInstructor notes
Speed toggle hardware practice

The simulator exercise fixed the difference between a button being held and a button being pressed once. Now verify that behavior on the robot.

Prepare the robot

  1. Confirm that the repaired code has been built and the Robot Controller app is connected to the Driver Station.
  2. Choose the preconfigured drive profile and select [S2-02] Speed toggle - Solution.
  3. Connect the gamepad as gamepad1.

Test the repaired behavior

  1. Place the robot in a clear, safe practice area and wait for instructor approval.
  2. Press INIT, then START.
  3. Drive slowly and tap the right bumper once. Confirm the speed changes once.
  4. Hold the right bumper. Confirm the speed does not keep changing while it is held.
  5. Release the bumper, then tap it again. Confirm the next tap changes the mode once.
  6. Press STOP before changing the OpMode or disconnecting equipment.

Takeaway

The physical test confirms that the program remembers the previous button state and responds to a new press rather than every loop while the button is held.

If the robot moves unexpectedly, release the controls and press STOP. Do not try to correct a moving robot by hand.
