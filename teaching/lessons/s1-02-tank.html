Motor direction repair

This is your first code repair. The exercise compiles, but the motor directions are intentionally wrong. Find the pattern, change one direction setting at a time, and retest.

Your goal

  1. Run [S1-02] Tank - Exercise in the simulator.
  2. Use the controls and telemetry to describe what is wrong.
  3. Find the motor direction assignments in S1_02_TankExerciseTeleOp.java.
  4. Change the direction settings to match the diagram.
  5. Run the same test again and explain what improved.

What does motor direction mean?

A motor's FORWARD and REVERSE settings describe how its electrical positive direction is interpreted by the software. They do not mean “the robot moves forward” or “the robot moves backward.”

Wheels on opposite sides of a drivetrain are mounted as mirror images. If the same positive command is sent to every motor, one side may turn the wheel in the wrong physical direction. We reverse the motors on one side so that the same drive command makes all four wheels help the robot move together.

Expected direction pattern

Top view: front is at the top. LF = left front, RF = right front, LB = left back, and RB = right back.

Use the diagram as a reference while comparing the four assignments. The exercise starts with all four directions set the same way, so forward or backward input makes the robot spin in a circle. The correct pattern lets the robot drive straight and turn in place instead of fighting itself.

Read before editing

  1. In init(), find the four hardwareMap.get(...) lines. These names must match the robot configuration.
  2. Find the four direction assignments. The exercise intentionally starts with all four set to FORWARD.
  3. In loop(), find the forward and rotate inputs, then the left and right power calculations.
  4. Find where one calculated power is sent to both motors on the same side.

Test, edit, retest

  1. Start with both sticks released. Confirm the robot is still.
  2. Move the left stick forward a small amount. Observe the robot spin in a circle instead of driving straight.
  3. Move the left stick backward. Confirm that the wrong behavior reverses direction but still spins.
  4. Use the diagram and your observations to decide which side needs REVERSE.
  5. Stop the OpMode, change only the needed direction assignments, rebuild, and run the exercise again.
  6. Repeat the forward and turn tests. Compare the result with [S1-02] Tank - Solution.

Takeaway

By the end of this lesson, every student should be able to explain that motor direction is a configuration choice made during init(), use behavior to identify a drivetrain-side mismatch, make a controlled edit, and prove the fix by retesting.
