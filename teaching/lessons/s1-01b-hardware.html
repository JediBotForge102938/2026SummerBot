S1-01B · Drive the real robot

Repeat the simulator workflow on the physical robot with a preconfigured Driver Station.

Course mapMissionResourcesInstructor notes
Robot app deployment

The instructor has already prepared the robot configuration. Your job is to use the Android Studio run configuration, watch for the controller to become ready, and then repeat the same INIT, START, and drive cycle from the simulator.

Robot Rotation

Three teams share one robot, so the instructor deploys the app once and gives each team one equal turn. During your turn, use driver, navigator, and observer/debugger roles. Test forward, reverse, turn, and stop; switch roles quickly so every student participates. Code edits happen in the simulator, not beside the active robot.

Connect and run the app

  1. Connect the computer to the REV controller with the approved USB cable. Keep the robot supported safely and do not move the wheels yet.
  2. In Android Studio, select the FtcRobotController run configuration.
  3. Click the green Run button. Android Studio builds and pushes the Robot Controller app to the REV controller.
  4. Watch the REV controller. A flashing blue light means it is active during the connection and deployment process. Do not unplug it while Android Studio is still deploying.
  5. Wait for the deployment to finish and for the Robot Controller app to be ready before opening the Driver Station.

Prepare the Driver Station

  1. Turn on the Driver Station phone and open the FTC Driver Station app.
  2. Confirm that the Driver Station is connected to the Robot Controller. Ask the instructor for help if the connection indicator is not ready.
  3. Open the robot configuration screen and choose the preconfigured drive profile. This profile was prepared by the instructor; configuration changes will be taught in a later lesson.
  4. Return to the OpMode list and select [S1-01] Workflow.
  5. Connect the gamepad to the Driver Station and confirm it is assigned as gamepad1.

INIT, START, and drive

  1. Place the robot in a clear, safe practice area. Keep hands and feet away from the wheels and wait for the instructor's approval.
  2. Press INIT. Compare the Driver Station telemetry with what you saw in the simulator.
  3. Press START. Move the left stick slightly forward and release it. The robot should stop.
  4. Move the right stick X slightly and release it. The robot should turn in place.
  5. Repeat the forward, turn, and combined-motion tests at low speed.
  6. Press STOP before changing the OpMode or disconnecting equipment.

Takeaway

The simulator and robot use the same student OpMode. The run configuration transfers the app; the Driver Station selects and controls the OpMode. Students should be able to explain which computer performs each job and why the first physical test is slow and supervised.

If the robot moves unexpectedly, release the controls and press STOP. Do not try to correct a moving robot by hand.
